English → SQL Web App
=====================

REQUIREMENTS
  Python 3.9+  |  An OpenAI API key (https://platform.openai.com/api-keys)

SETUP (run once)
  pip install -r requirements.txt

START THE SERVER
  python app.py

  Then open your browser at:  http://localhost:5000

HOW TO USE
  1. Paste your OpenAI API key in the sidebar (sk-...)
  2. Drag & drop any SQLite .db file into the upload zone
  3. Your database schema appears automatically in the sidebar
  4. Type any question in plain English (or click an example chip)
  5. Press ▶ Run  (or Ctrl+Enter / Cmd+Enter)
  6. See the generated SQL, results table, and auto-debug log

NOTES
  - The app supports any SQLite .db file — not just the sample one
  - If SQL fails, the engine retries up to 3 times automatically,
    feeding the error back to GPT-4o each time
  - Unsafe operations (DROP / DELETE / ALTER) are blocked by default
